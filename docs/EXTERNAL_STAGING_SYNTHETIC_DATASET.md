# Dataset sintético de staging externo

Os perfis são `DISPOSABLE_REHEARSAL` (dois tenants e testes cross-tenant) e `EXTERNAL_STAGING_PILOT` (somente tenant piloto). O perfil externo deve conter clínica, profissionais, procedimentos, pacientes, leads, agendamentos, orçamentos, inbox interna, entitlement não pago e credencial sintética hashada. São proibidos Checkout, cobrança confirmada, integração conectada, provider real e mensagem externa `SENT`.
